# Exam Project

This project contains our solutions to the three problems in the Programming for Economists exam.

## Files

- `SolowModel.py` contains the Solow model used in Problem 2.
- `PortfolioModel.py` contains the portfolio model used in Problem 3.
- `states.py` contains the state and region information used in Problem 1.
- `results.ipynb` contains the results, figures, explanations and answers to the different problems.

## Running the project

Open `Results.ipynb` in the same folder as the `.py` files and run all cells from the top.

The project uses `numpy`, `scipy`, `pandas`, `matplotlib` and `fredapi`.
